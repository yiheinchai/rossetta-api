🔍 Test Rossetta Packages Here!

This is a simple, unencrypted chat app. Perfect for testing the Rossetta packages:

  1. Install: pip install rossetta-fastapi
  2. Add one line to main.py: app.add_middleware(RossettaMiddleware)
  3. Watch the network tab - all requests will be encrypted!
